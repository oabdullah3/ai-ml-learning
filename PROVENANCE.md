## Anonymisation

The internship work was originally built for a client. To respect confidentiality:

- The government-citizen hotline client is referred to generically as **"a government hotline"** (no jurisdiction, agency name, or contact details appear anywhere in the code or docs).
- Company-specific branding, internal handles, telemetry endpoints, and employee identifiers have been stripped or neutralised (`telemetry.example.invalid`).
- No client data is committed. Real email correspondence, survey responses, and network attribute files are **excluded** — the code references them by filename only, and each affected project's README documents the expected input schema so it can be reproduced with your own data.
